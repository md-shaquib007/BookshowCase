# 📚 MyBook — Digital Book Showcase

An enterprise-grade, accessible, and responsive digital bookshelf web application built with modern HTML5, CSS3 custom properties, and JavaScript.

## 🌟 Key Features

- **Curated Catalogue**: Explore tech and computer science titles with clean typography and cover illustrations.
- **Client-Side Live Search**: Real-time search filtering by book title or topic category on `book_showcase.html`.
- **Interactive Feedback**: Client-side validated sign-in and book review submission with toast notifications.
- **Responsive & Mobile Ready**: Custom breakpoints and accessible hamburger drawer navigation for mobile devices.
- **SEO & Social Optimization**: Includes Open Graph tags, JSON-LD structured data (`WebSite`, `ItemList`, `Book`), and custom SVG favicons.
- **Accessibility & Motion Guards**: WCAG-compliant color contrast, keyboard focus indicators, and `prefers-reduced-motion` guards.

## 📁 File Structure

- `index.html` — Hero landing page & value proposition
- `book_showcase.html` — Interactive collection catalogue with search
- `book_login.html` — Validated user authentication interface
- `book1-details.html` — Computer Networking details
- `book2-details.html` — Artificial Intelligence details
- `book3-details.html` — Theory of Computation details
- `styles.css` — Enterprise modular design system & responsive utility styles
- `404.html` — Custom fallback error page
